## The title

> Senior Vice President of Apologising to the Printer

1 printer, 47 apologies, 0 promotions: the title opens with the highest corporate rank, then the twist — the whole executive exists only to apologise — and lands on the one machine every worker has already begged, threatened, and apologised to. It sounds like a real job because the rank is real; it is weird because the job is apologising to a printer.
